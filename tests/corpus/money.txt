# Money notes and what they mean, for the phone's own reader (lib/understand.ts).
# Run: npm run corpus   (prints the score and every miss)
#
# One note per line:   text  =>  expected
#   expected: "metric value" pairs, comma-separated, in the order said; or "none" (no money in it).
#   metrics:  spent, received, owe (you owe), lent (owed to you), planned (still to pay), price.
# Start a line with "~" for a known gap: what it should read, which the reader doesn't yet.
#   A known gap is reported, not failed; once it reads right the run fails until the "~" is removed.
# Add real notes here whenever the phone gets one wrong: a new phrasing is a new line, then a fix
# that the whole file must still pass.
